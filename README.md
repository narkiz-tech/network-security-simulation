Technologies Used
- Cisco Packet Tracer
- Cisco IOS CLI
- EIGRP Routing Protocol
- Access Control Lists (ACLs)
- Theoretical CBAC configuration

Project Features
- Configured routers and interfaces (R1, R2, R3)
- Applied ACLs to control and filter inbound traffic
- Simulated network segmentation (internal vs external)
- Included command-line validation using `show ip interface brief`, `show run`
- Theoretical setup for CBAC firewall (not supported in Packet Tracer)

Files Included
- `network.pkt`: Cisco Packet Tracer project file
- `commands-used.txt`: CLI commands for router configuration
- `/images`: Screenshots of the project and console outputs

Security Goals
- Protect internal networks from untrusted external access
- Implement default-deny rule with ACLs
- Understand principles of stateful firewalling using CBAC

Learning Outcomes
- Hands-on experience with ACLs and router CLI configuration
- Gained insights into basic firewall principles
- Understood limitations of simulation tools like Packet Tracer for advanced features
